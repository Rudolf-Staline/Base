# BaseKit — documentation générique

BaseKit est une bibliothèque UI pure : composants génériques, tokens de design system, moteur déclaratif et registry React.

Les exemples doivent rester neutres : Item A, Item B, Utilisateur, Projet, Statut, Date, Quantité, Option A et Option B.

Aucun composant métier ni mini-application métier ne fait partie de BaseKit. Les projets consommateurs composent leurs propres écrans avec les briques génériques.
